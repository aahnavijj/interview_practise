## 🧠 Interview Approach

For each problem, I try to follow a consistent approach:

### For coding problems

1. Understand the problem
2. Identify the pattern
3. Explain the approach
4. Write the solution
5. Walk through an example
6. Discuss edge cases
7. Analyze time complexity
8. Analyze space complexity

### For system design

1. Functional Requirements
2. Non-Functional Requirements
3. Architecture
4. Data Layer / API
5. State Management
6. URL / Routing
7. Caching
8. Performance
9. Error Handling
10. Trade-offs

### For theoretical questions

1. Definition
2. Why it exists
3. How it works
4. Example
5. Common interview follow-ups
6. Practical use case
